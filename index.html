وتحسين المواقع

أعمل على اكتشاف الأخطاء البرمجية وإصلاحها وتحسين أداء وواجهة المواقع والتطبيقات، مع الاهتمام بالكود النظيف والنتيجة النهائية.

معرض الأعمال

أمثلة توضيحية على مشاكل برمجية قبل الإصلاح وبعده

01 — إصلاح مشكلة JavaScript

حل خطأ كان يمنع الزر من تنفيذ الوظيفة المطلوبة.

قبل الإصلاح
const btn = document.querySelector('#send');

btn.addEventListener('click', sendMessage
// SyntaxError: missing )
بعد الإصلاح
const btn = document.querySelector('#send');

btn.addEventListener('click', sendMessage);

function sendMessage() {
  console.log('Message sent');
}
✓ تم إصلاح الخطأ وإعادة تشغيل الوظيفة بشكل صحيح.

02 — إصلاح مشكلة CSS

حل مشكلة اختفاء المحتوى بسبب تنسيق غير صحيح.

قبل الإصلاح
.card {
  width: 100%;
  height: 0;
  overflow: hidden;
}
بعد الإصلاح
.card {
  width: 100%;
  min-height: 180px;
  overflow: visible;
  padding: 20px;
}
✓ ظهر المحتوى بشكل صحيح مع الحفاظ على التصميم المتجاوب.

03 — إصلاح نموذج تسجيل

إضافة التحقق من البيانات قبل إرسال النموذج.

قبل الإصلاح
form.addEventListener('submit', e => {
  // إرسال مباشر
  submitForm();
});
بعد الإصلاح
form.addEventListener('submit', e => {
  e.preventDefault();

  if (!email.value.includes('@')) {
    return showError('Email is invalid');
  }

  submitForm();
});
✓ تم منع البيانات غير الصحيحة وتحسين تجربة المستخدم.

04 — تحسين كود API

معالجة الأخطاء وإضافة حالة واضحة عند فشل الاتصال.

قبل الإصلاح
fetch('/api/data')
  .then(r => r.json())
  .then(data => render(data));
بعد الإصلاح
fetch('/api/data')
  .then(r => {
    if (!r.ok) throw new Error('Request failed');
    return r.json();
  })
  .then(data => render(data))
  .catch(() => showError('حدث خطأ، حاول مرة أخرى'));
✓ أصبحت أخطاء الاتصال معالجة بدل توقف الصفحة.
